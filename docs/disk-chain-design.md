# ディスク列 (endgame h5) 設計 — 第67ループ確定版 (ζ経路)

目標 (endgame h5): `∀ s, 1/2 ≤ re ≤ 77/128 → 863/64 ≤ im ≤ 71/5 → ζ(s)=0 → re=1/2`

## 骨格 (両方とも kernel-checked + promoted)

| claim | f | 中心値下界 q の入手 | 球面上界 M の入手 |
|---|---|---|---|
| `disk-off-line-exclusion` [9acf95a0a43d] | ξ | Γ(s/2) 値球パイプライン (**複数ループ規模**) | 関数等式で右半円のみ評価 (σ≥1/2) |
| **`disk-off-line-exclusion-zeta` [6caade12a21b]** | **ζ** | **`certify-zeta-point` (既存・完動)** | σ<1/2 側に m 一般化 η が必要 |

論法 (共通): 線上中心 c = 1/2+τi の閉球内に非実零点 s があれば、反射点
1−s̄ も零点で **中心が線上ゆえ c から厳密に等距離**。re s ≠ 1/2 なら相異なる
2零点となり、two-zero-disk-bound [1b1745d965c9] が
‖f(c)‖ ≤ M·r²/(R−r)² < q ≤ ‖f(c)‖ の矛盾を与える。

ζ 版の正則性条件は `R < τ` のみ (閉球上 im > 0 ⟹ s ≠ 1)。ξ 版は整関数
[8ca2eb621d8c] なので条件なし。ζ 版は反射に reflect-pair [d7dbec8fcb2e] を
直接使う (ξ への転送が不要)。

**採用: ζ 版**。q が既存エミッタで出るため、残る未完部品は M ただ1つ。

## 適用: `certify-disk-rect` (実装済み)

閉矩形 σ∈[σlo,σhi] × t∈[tlo,thi] が ball(1/2+τi, r) に内接する条件
a² + b² ≤ r² (a = σhi−1/2, b = max(τ−tlo, thi−τ)) と円板不等式
M·r²/(R−r)² < q を Rust が厳密検査し、Lean は norm-le-of-re-im
[3be59de0350d] + 骨格で再導出する。※現状は ξ 版を呼ぶ — ζ 版への切替は
1行 (claim id と結論の im≠0 仮定の供給を h3 から取る)。

## 残る唯一の数値部品: 球面上界 M

円 |z−c| = R は σ ∈ [1/2−R, 1/2+R] に及ぶ。ζ = η/(1−2^{1−s}) から
‖ζ‖ ≤ ‖η‖ / min|1−2^{1−s}| で評価する:

1. **‖η‖ 上界**: 部分和 Σ_{n<N} n^{−σ} (σ ≥ σmin で単調) + Boole 剰余。
   剰余は `eta-boole4-uniform` [2c18454eb321] が **σ ≥ 1/2 限定** なので、
   **m 一般化版が必要** — 仮定 `1/2 ≤ s.re` → `m ≤ s.re`、
   結論の `N^{-7/2}` → `N^{-(m+3)}`。既存証明のパラメータ化で、
   新しい解析は不要 (第68ループの主目標)。
2. **除数下界** min|1−2^{1−s}|: σ ≤ 1/2+R < 1、t ∈ [τ−R, τ+R] は除数零点
   (σ=1, t=2πk/log2 ≈ 9.06k) から離れているので norm_num 級。
3. R の選択: 1/2−R > 0 が必要 (η 級数の収束域)。R ≈ 0.45、r ≈ 0.12 なら
   r²/(R−r)² ≈ 0.132 で、M ≈ 3 に対し q > 0.40 が要る。
