目標 (endgame の**唯一残る仮定**):
`∀ s, 1/2 ≤ re ≤ 77/128 → 863/64 ≤ im ≤ 71/5 → ζ(s)=0 → re=1/2`

論法: 線上中心 c=1/2+τi の閉球内の非実零点 s に対し反射点 1−s̄ も零点で
c から**厳密に等距離**。re s ≠ 1/2 なら相異なる2零点となり
‖ζ(c)‖ ≤ M·r²/(R−r)² < q ≤ ‖ζ(c)‖ の矛盾。正則性条件は R < τ のみ。

## 残る2部品

### (1) 球面上界 M ≤ 0.8 (union 矩形 σ∈[0.05,0.95] × t∈[13.10,14.64])
`sphere c R ⊆ rect` のアダプタ (|z.re−1/2| ≤ R, |z.im−τ| ≤ R) で矩形版に帰着。
矩形上の ‖ζ‖ ≤ ‖η‖ / |1−2^{1−s}|:
- **‖η‖ 上界は crude な項別評価では 30倍以上損** (真の値 ~2 に対し ~27) ため
  **セル型 (アンカー球 + Lipschitz) が必須**。m = 0.05 で
  `eta-boole4-uniform-m [5e4811725a0f]` が使える (これが m 一般化の目的)。
  ML(N=30, m=0.05) ≈ 67 なので、余裕 ~2 に対しセル径 ~0.047
  → 0.9 × 1.54 の矩形で **~650セル** (既存キャンペーン規模の 1/7)。
- **除数下界**: t∈[13.10,14.64] で t·log2 mod 2π ∈ [2.75, 3.87] (π 近傍) ゆえ
  Re(2^{1−s}) < 0、|1−2^{1−s}| ≥ 1.78。σ 依存は modulus 2^{1−σ} ≥ 1.035 のみ。
  t 区間1本の cos 上界 (rotor/u-chain) で足りる。
