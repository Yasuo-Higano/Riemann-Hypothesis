## 運用上の既知の罠 (再発防止)

- キャンペーン走行中の `cargo build` は禁止 → scripts は `RH_BIN`
  (既定 `target/rh-stable`) を使う。
- kill された promote-batch の残骸は dirty workspace となり、後続 verify の
  偽タイムアウトを誘発する → 先に `lake build` で整地する。
- セルは格子点 t_j = t0 + jδ を**中心**に [t_j ± δ/2] を覆う。補充グリッドの
  t0 は「境界 − δ/2」。
- σc アンカーは**小分母** (≤128) 必須。rpow ブラケットが x^den·n^num になり、
  大分母では norm_num が通らない。
- 8.5 = 17/2 (19/2 は 9.5)。弱化の端点指定で取り違えやすい。
